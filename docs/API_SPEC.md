# INSight OS API Spec

## 0. Scope

This spec freezes the v0.2 Content Library API.

Only three endpoints are required:

```text
POST /content/import
GET  /content
POST /content/analyze
```

## 1. POST /content/import

Import content from CSV, URL/manual payload, or future integration adapters.

### Request: single item

```json
{
  "items": [
    {
      "title": "王府井上半年新增首店31家",
      "content_source": "news",
      "platform": "news",
      "source_name": "人民网",
      "source_type": "news",
      "url": "https://example.com/article",
      "author": "人民网",
      "published_at": "2026-07-01T09:00:00+08:00",
      "raw_text": "正文内容"
    }
  ]
}
```

### Response

```json
{
  "created": 1,
  "skipped": 0,
  "failed": 0,
  "items": [
    {
      "id": "uuid",
      "title": "王府井上半年新增首店31家",
      "content_status": "new"
    }
  ],
  "errors": []
}
```

### Rules

- Duplicate URL should be skipped, not duplicated.
- Records are saved with `content_status = new`.
- UUID is generated by database.

## 2. GET /content

List content with pagination, search, filters, and sorting.

### Query Parameters

```text
page=1
page_size=20
q=王府井
platform=news
content_source=article
content_status=analyzed
city=北京
category=商业地产
competitor_id=uuid
published_from=2026-07-01
published_to=2026-07-07
sort=published_at
order=desc
```

### Response

```json
{
  "page": 1,
  "page_size": 20,
  "total": 42,
  "items": [
    {
      "id": "uuid",
      "title": "王府井上半年新增首店31家",
      "content_source": "news",
      "platform": "news",
      "source_name": "人民网",
      "published_at": "2026-07-01T09:00:00+08:00",
      "summary": "100字摘要",
      "tags": ["首店经济", "国际消费"],
      "content_status": "analyzed",
      "analysis_status": "completed",
      "analysis_version": "gpt55-v1"
    }
  ]
}
```

## 3. POST /content/analyze

Analyze one or more content records.

### Request

```json
{
  "content_ids": ["uuid"],
  "analysis_version": "gpt55-v1",
  "force": false
}
```

### Response

```json
{
  "analyzed": 1,
  "failed": 0,
  "items": [
    {
      "id": "uuid",
      "summary": "100字摘要",
      "tags": ["Citywalk", "商业地产"],
      "keywords": ["王府井", "首店", "外卡支付"],
      "scores": {
        "heat_score": 82,
        "brand_fit_in77": 61,
        "brand_fit_in88": 91,
        "innovation_score": 78,
        "execution_score": 84
      },
      "suitable_for": ["in88"],
      "recommendation": "可作为王府井首店经济选题参考。",
      "analysis_version": "gpt55-v1",
      "prompt_version": "v1",
      "brand_brain_version": "1.0",
      "score_version": "1.0",
      "workflow_version": "0.1",
      "analysis_trace": {
        "provider": "openai",
        "model": "gpt-5.5",
        "prompt_version": "v1",
        "brand_brain_version": "1.0",
        "trend_version": "0.1",
        "score_version": "1.0",
        "workflow_version": "alpha",
        "analysis_time_ms": 6234,
        "fallback": false
      }
    }
  ],
  "errors": []
}
```

### Rules

- AI output must be parsed into structured fields.
- `analysis_status` must move from `pending` to `completed`, or `failed` on error.
- `analysis_version` must be saved.
- `prompt_version` must be saved.
- `brand_brain_version` must be saved.
- `score_version` must be saved.
- `workflow_version` must be saved.
- `analysis_trace` must be saved.
- Malformed AI JSON must return a useful error.
- Failed items should not block successful items.
