# INSight OS Definition of Done

## 0. Purpose

This document defines what "done" means for Sprint 2 and future work.

An endpoint is not done just because it runs. It is done only when it meets product, API, data, error handling, documentation, and test criteria.

## 1. Global DoD

Every feature must satisfy:

- Uses the frozen data model or includes an approved migration note.
- Follows Router -> Service -> Repository -> Database.
- Returns structured JSON.
- Has error handling.
- Has basic tests or a documented manual verification path.
- Updates API documentation.
- Supports the North Star: better content decisions, not more content for its own sake.

## 2. POST /content/import

Done means:

- CSV import works.
- URL/manual payload import works.
- Duplicate detection works by URL where available.
- UUID is generated by database.
- `content_status = new`.
- `content_source` is set.
- `analysis_version` is empty or null before analysis.
- Returns structured JSON.
- Invalid rows return useful errors.
- Import result includes created, skipped, and failed counts.
- Unit or integration test exists.
- API spec is documented in `docs/API_SPEC.md`.

## 3. GET /content

Done means:

- Pagination works.
- Search works across title, source, summary, and keywords where feasible.
- Filters work:
  - platform
  - content_source
  - content_status
  - city
  - category
  - competitor_id
  - published_at range
- Sorting works by published_at and collected_at.
- Returns JSON.
- Swagger/OpenAPI includes endpoint details.
- Empty result is handled cleanly.
- Unit or integration test exists.

## 4. POST /content/analyze

Done means:

- GPT call succeeds with configured model.
- Summary is generated.
- Tags are generated.
- Scores are generated.
- Suitable project is generated.
- Evidence/reason is generated.
- Result is saved to database.
- `content_status = analyzed`.
- `analysis_version` is saved.
- `prompt_version` is saved.
- `brand_brain_version` is saved.
- `score_version` is saved.
- `workflow_version` is saved.
- `analysis_trace` is saved.
- Timeout target is under 15 seconds per ordinary content item.
- Retry mechanism exists for transient AI/API errors.
- Error handling exists for missing content, failed AI call, and malformed AI JSON.
- Unit or integration test exists.
- API spec is documented in `docs/API_SPEC.md`.

## 5. v0.2 Demo Day DoD

v0.2 is done only when:

- 20 content items can be imported.
- AI analysis runs on imported items.
- Dashboard or temporary UI can show:
  - Today
  - Content
  - Trend
  - Idea
- A content operator can understand what to do next.
