# Demo Script

Goal: demonstrate the complete Beta flow in 10 minutes.

## Preparation

- Backend is running.
- Frontend `frontend/content-library.html` is open.
- No manual database edits are allowed during demo.

## Flow

1. Import content
   - Use the Import Content panel.
   - Confirm imported records appear in Content Library.

2. Analyze
   - Click Analyze for imported records.
   - Confirm tags, scores, and status update.

3. Generate Trends
   - Click Generate Trends.
   - Confirm Today's Trends shows Top 5.

4. Generate Ideas
   - Click Generate Ideas.
   - Confirm Today's Ideas shows in77 and in88 recommendations.

5. Generate Weekly Report
   - Click Generate Report.
   - Confirm Markdown report appears.

6. Dashboard
   - Refresh Dashboard.
   - Confirm stats, top trends, top ideas, latest report, quick actions, and recent activity.

## Pass Criteria

- All steps complete without manual database edits.
- Dashboard answers: 今天内容团队最应该关注什么？
- Report preserves trend, idea, and content references.
