# INSight OS PRD

## Product

INSight OS is an **AI Content Operating System for Commercial Real Estate**.

Initial scope:

- Beijing in77
- Beijing Wangfujing Intime in88

## Product Goal

```text
Daily content collection
  -> weekly AI analysis
  -> project-specific ideas
  -> weekly report
```

## MVP

The MVP focuses on one complete workflow:

```text
Import content
  -> AI summary
  -> AI tags
  -> AI scoring
  -> trend generation
  -> 5 ideas for in77
  -> 5 ideas for in88
  -> Markdown weekly report
```

## Core Modules

- Content Library
- Competitor Library
- Trend Center
- Idea Pool
- Weekly Reports
- AI Service
- Brand Brain
- Decision Engine
- Explainability Framework
- Strategy Engine

## Success Criteria

The MVP succeeds when weekly report preparation time drops from 3+ hours to 30 minutes.
