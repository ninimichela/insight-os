# Architecture Decision Records

Architecture decisions for INSight OS are recorded here.

Rules:

- New architecture decisions must be added as ADR files.
- Do not leave architecture decisions only in chat history.
- ADRs are append-only unless correcting typos or clarifying wording.
- If a decision changes, create a new ADR that supersedes the old one.

Format:

```text
# ADR XXXX: Title

## Status

Accepted / Superseded / Proposed

## Context

Why this decision matters.

## Decision

What we decided.

## Consequences

Tradeoffs and implications.
```
