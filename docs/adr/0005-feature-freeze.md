# ADR 0005: Feature Freeze Before MVP

## Status

Accepted

## Context

The largest risk is scope expansion. The product already has enough architecture to support MVP and v1.0.

## Decision

Use the rule:

```text
No New Engine Before MVP
```

Before `v1.0`, do not add new engines, databases, workflows, or prompt categories.

## Consequences

- Work focuses on shipping the MVP.
- New ideas must be deferred unless they complete existing scope.
- Product decisions must support the North Star: better content decisions, not more content generation.
