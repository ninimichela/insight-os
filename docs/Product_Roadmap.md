# INSight OS Product Roadmap

## Product Positioning

INSight OS is an **AI Content Operating System for Commercial Real Estate**.

It is not a copywriting tool. It is a content intelligence system that combines market content, competitor analysis, brand memory, decision logic, and performance feedback.

## 2026 Q3: Alpha

Goal:

Run the first useful Content Library and AI Analysis workflow.

Scope:

- Content Library
- Competitor Library
- Basic AI analysis
- Manual CSV import
- Basic dashboard

Release targets:

- `v0.1`: Repo scaffold, CI, Docker, docs
- `Alpha`: Content Library, import, AI analysis

## 2026 Q4: Beta

Goal:

Complete the first weekly planning loop.

Scope:

- Trend
- Idea
- Weekly Report
- Dashboard improvements

## 2027 Q1: Release Candidate

Goal:

Make AI recommendations more brand-specific and explainable.

Scope:

- Brand Brain
- Decision Engine
- Memory Layer
- Explainability Framework
- Prompt Composer
- Duplicate idea detection

## 2027 Q2: 1.0 Commercial Release

Goal:

Prepare INSight OS for commercial use.

Scope:

- Performance Database
- Strategy Engine
- Monthly content matrix
- Campaign planning
- KPI-based recommendations
- Dashboard analytics
- Enterprise version
- Team version
- Multi-brand workspace
- API
- Role permissions
- Integrations
- Deployment templates
