# INSight OS Product Roadmap

## Product Positioning

INSight OS is an **AI Content Operating System for Commercial Real Estate**.

It is not a copywriting tool. It is a content intelligence system that combines market content, competitor analysis, brand memory, decision logic, and performance feedback.

## 2026 Q3: MVP

Goal:

Run the first useful weekly content workflow.

Scope:

- Content Library
- Competitor Library
- Trend Center
- Idea Pool
- Markdown Weekly Report
- Basic AI analysis
- Manual CSV import
- Basic dashboard

Release targets:

- `v0.1`: Repo scaffold, CI, Docker, docs
- `v0.2`: Database and content import
- `v0.3`: AI analysis service
- `v0.4`: Dashboard
- `v0.5`: End-to-end MVP

## 2026 Q4: Intelligence Layer

Goal:

Make AI recommendations more brand-specific and explainable.

Scope:

- Brand Brain
- Decision Engine
- Memory Layer
- Explainability Framework
- Prompt Composer
- Duplicate idea detection

## 2027 Q1: Strategy Layer

Goal:

Move from weekly ideas to monthly and campaign strategy.

Scope:

- Performance Database
- Strategy Engine
- Monthly content matrix
- Campaign planning
- KPI-based recommendations
- Dashboard analytics

## 2027 Q2: SaaS Layer

Goal:

Make INSight OS reusable for multiple commercial real estate clients.

Scope:

- Enterprise version
- Team version
- Multi-brand workspace
- API
- Role permissions
- Integrations
- Deployment templates
