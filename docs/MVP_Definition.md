# INSight OS MVP Definition

## 1. MVP Definition

The INSight OS MVP is successful when one content operator can import competitor and market content, run AI analysis, generate project-specific ideas, and export a weekly Markdown report for in77 and in88.

The first MVP does not need full automatic scraping, SaaS permissions, PPT export, or advanced Brand Brain. It must prove the weekly planning workflow.

## 2. MVP Core Workflow

```text
Import WeChat / Xiaohongshu / news content
  ↓
AI summary
  ↓
AI tags
  ↓
AI scoring
  ↓
Trend generation
  ↓
Generate 5 ideas for in77
  ↓
Generate 5 ideas for in88
  ↓
Generate Markdown weekly report
```

## 3. MVP Success Criteria

| Workflow | Current Manual Time | MVP Target Time |
| --- | ---: | ---: |
| Content collection | 30 min | 5 min |
| Competitor analysis | 60 min | 10 min |
| Idea generation | 90 min | 20 min |
| Weekly report assembly | 120 min | 30 min |

Target weekly time saved:

```text
8 hours per week
```

## 4. Functional Acceptance Criteria

MVP must support:

- Import at least 20 content items.
- Store content in a real database.
- Run AI analysis for summary, tags, scores, and recommendations.
- Generate trends from analyzed content.
- Generate 5 ideas for in77.
- Generate 5 ideas for in88.
- Generate one Markdown weekly report.
- Show Content, Trends, Ideas, and Reports in a web dashboard.

## 5. Non-goals for MVP

MVP does not include:

- Fully automated Xiaohongshu scraping.
- Fully automated WeChat scraping.
- PPT export.
- Team permission management.
- Full Brand Brain learning loop.
- Performance feedback loop.
- SaaS billing.

## 6. MVP KPI

Primary KPI:

```text
Weekly report preparation time reduced from 3+ hours to 30 minutes.
```

Secondary KPIs:

- 80% of generated ideas are usable for discussion.
- Weekly report includes traceable evidence for each recommendation.
- Content team can complete a planning meeting using the generated report.
